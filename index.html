HOW TO USE

把架构图和执行链路连起来看

01 选路径

左侧五个入口：芯片总览、单芯片实验室、多芯片对比、统一模型 · 8 卡、Runtime 能力。先看总览，再进单芯片。

02 看模块

悬停任意模块，高亮并显示功能；点击锁定，右侧展开内部结构、关键事实和相关术语。Host 用户态、kernel driver、设备控制、PE 是分开的。

03 学概念

点击“发射 / 驱动 / 控制 / 依赖 / 同步 / 通信”，相关模块一起高亮，右侧给出当前芯片上的具体对应物。

04 跑任务

点击“下发任务”，观察一层 decode 如何从 Host 用户态 → kernel driver → 设备控制/调度 → PE 计算 → barrier → all-reduce。

05 画幅 / 数据流

单芯片画布支持滚轮缩放、中键拖动和“重置画幅”；统一模型板块用 8×8 矩阵播放切分 / partial / AllReduce。

颜色按“控制 / 计算 / 存储 / 互联 / 同步 / 驱动”分组；同一色系代表同一类职责。对比、统一模型、runtime 能力是三个独立板块，不挤在单芯片图里。
